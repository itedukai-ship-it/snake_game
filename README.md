# 🐍 Snake на Python (turtle)

Простая игра «Змейка», написанная на Python с использованием встроенной библиотеки
`turtle` — без установки внешних зависимостей (в отличие от версии на `pygame`).

Проект создан как учебный пример для видео на YouTube-канале **ITeduka.cz**.

▶️ **Видео-урок:** https://youtu.be/8Xl_VA2_bT8

---

## 📋 Что внутри

- `snake_turtle.py` — основной код игры
- `apple.gif` — картинка яблока (еда), 30×30 px
- `snake_head.gif` — картинка головы змейки, 30×30 px
- `snake_body.gif` — сегмент тела змейки, 20×20 px

## 🎮 Как играть

- Управление — стрелки на клавиатуре (↑ ↓ ← →)
- Цель — съедать яблоки и набирать очки, не врезаясь в стену или в собственный хвост
- При столкновении игра сбрасывается, но рекорд (`high_score`) сохраняется до закрытия окна

## ⚙️ Требования

- Python 3.x (библиотека `turtle` входит в стандартную библиотеку — ничего
  дополнительно устанавливать не нужно)
- На некоторых дистрибутивах Linux может понадобиться доустановить пакет Tk:
  ```
  sudo apt install python3-tk
  ```

## 🚀 Как запустить

1. Скачайте или клонируйте репозиторий:
   ```
   git clone <ссылка на этот репозиторий>
   ```
2. Убедитесь, что файлы `apple.gif`, `snake_head.gif` и `snake_body.gif`
   находятся в той же папке, что и `snake_turtle.py`
3. Запустите игру:
   ```
   python snake_turtle.py
   ```

## 💡 Об изображениях

`turtle` поддерживает только формат `.gif` для пользовательских форм, и не
масштабирует картинки — размер на экране равен размеру файла в пикселях.
Шаг движения змейки в коде — 20px, поэтому `snake_body.gif` сделан ровно
20×20, а голова и яблоко — крупнее (30×30) для визуального акцента.
